## 🧼 About The Project

A commercial landing page designed to turn online visitors into residential and corporate laundry customers. The layout emphasizes home pickup convenience and transparent service pricing.

### ✨ Features
- **Floating Header Navigation:** Seamless navigation with quick jumps to services, pricing, and contact.
- **Transparent Price List:** Clear visual breakdown for dry cleaning, bed & bath, and delicate garments.
- **Direct WhatsApp Scheduling:** CTA buttons initiating instant chat with pre-configured booking details.
- **Hosted on GitHub Pages:** Lightweight, static architecture with near-instant loading times.
