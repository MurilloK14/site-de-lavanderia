## 🧼 Sobre o Projeto

Landing page comercial projetada para converter visitantes em clientes de serviços de lavanderia residencial e corporativa. O layout destaca a praticidade da coleta domiciliar e disponibiliza uma visualização transparente de preços e planos.

### ✨ Funcionalidades
- **Barra de Navegação Flutuante:** Navegação intuitiva com links rápidos para serviços, preços e contato.
- **Tabela de Preços Detalhada:** Informações visuais sobre lavagem a seco, cama, mesa & banho e cuidados especiais.
- **Agendamento via WhatsApp:** Botões de CTA que iniciam conversas diretas com mensagem pré-preenchida.
- **Hospedado no GitHub Pages:** Carregamento ultra-rápido e 100% estático.
